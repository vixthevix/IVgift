# IVgift

Make and edit your very own Generation IV Mystery Gift!

## Installation

### Requirements

Before you can compile IVgift, run:

- **Debian/Ubuntu/Mint**
  ```
  sudo apt install build-essential git
  ```
- **Arch**
  ```
  sudo pacman -S base-devel git make
  ```
- **Fedora**
  ```
  sudo dnf install @development-tools git
  ```

### Build

**Installing [cottage](https://github.com/vixthevix/cottage)**

IVgift uses the cottage framework for server hosting.

To include it, run:

```
#In the IVgift folder...

cd src
git clone https://github.com/vixthevix/cottage.git

#cottage is composed of header files, so no further building here.
```

**Building IVgift**

Run `./ivgiftMake` in the IVgift folder. Alternatively, run the script with your command line interpreter (e.g. `bash`, `zsh` etc.) or copy and run the `gcc` commands directly in your terminal. 

## Software guide

### Run

Run `./ivgiftRun` or `bin/ivgift` in the IVgift folder.

## More information

### Background

IVgift began as a new way to create and edit Mystery Gifts, originally to help with my work on [IVnet](https://github.com/vixthevix/IVnet). Due to the surprising lack of modern software for doing this, I decided to take this a bit more seriously, and thus IVgift was properly made.

It is also the first app that uses cottage for it's intended purpose (IVnet uses it, but on the backend exclusively). As cottage improves, so will IVgift.
