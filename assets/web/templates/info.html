Heya! x3 IVgift is a program that allows you to create and edit Generation IV Pokemon Mystery Gifts. Mystery Gift data is stored in the following formats: PGT - Pokemon Gift, 260 bytes, stores the data to be received in-game via the Mailman in the Poke-Mart. PCD - Pokemon Card Data, 856 bytes, stores the PGT alongside the Wonder Card information, such as text and icons. MYG - Mystery Gift, 936 bytes, a wrapper for the PCD data. This is the file that is sent during Mystery Gift transmission. Any one of these files can be uploaded for editing in IVgift. A collection of Mystery Gifts for Generation IV can be found at Project Pokemon. Additionally, your generated MYG/PCD files can be uploaded to your games via: PKHex IVnet (this method can be done directly with your physical game cartridges) I hope you enjoy using IVGift! - vixthevix, a Human from Earth
